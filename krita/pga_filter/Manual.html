PGA filter

Runs the effect in effect.py on the selected layer. An effect is two things from the notebook: PARAMS, the list of parameters, and a NumPy function apply(img, ...). The plugin builds a control for each parameter, shows a live preview, and writes the effect into the layer when you press Apply.

Installing

  1. In Krita, choose Tools > Scripts > Import Python Plugin from File and pick the zip for your system (pga_filter-windows.zip or pga_filter-linux.zip).
  2. Restart Krita, then tick PGA filter in Settings > Configure Krita > Python Plugin Manager.
  3. Restart Krita again. The filter is in Tools > Scripts, under the name in TITLE.

Editing the effect

Open the folder through Settings > Manage Resources > Open Resource Folder, then pykrita/pga_filter/effect.py. Paste PARAMS and apply from the notebook unchanged. The plugin reads the file again every time the filter opens, so Krita needs no restart after an edit.

img is a float32 array of shape (height, width, 4), channels RGBA from 0 to 1. apply returns an array of the same shape.

A colour arrives as the numbers the picker shows, with no conversion to linear light.

What the filter changes

  • Only a paint layer in the RGB colour model, at 8 or 16 bit integer or 16 or 32 bit float depth. A float layer may hold values above 1, and in a linear profile its numbers are linear light.
  • Only the selection, or the whole canvas when nothing is selected. A soft selection blends the result with the original layer smoothly.
  • The result replaces the layer with a copy under the same name. Writing pixels from Python makes no undo step in Krita, but adding and removing a layer do, so Ctrl+Z twice brings the original layer back.

Preview

"Whole region, scaled down" shows everything, "Centre at full size" a crop from the centre without scaling. An effect that reads neighbours, a blur for example, looks stronger in the scaled preview, because its radius in pixels covers more of the picture. An error in apply is printed in red under the preview, and Apply stays disabled until it is fixed.

A second filter beside this one

Copy the pga_filter folder and the pga_filter.desktop file under a new name, say my_filter, and in the .desktop file set X-KDE-Library to that name and Name to the name the Python Plugin Manager shows. The menu entry is named after TITLE.

When something fails

  • Krita could not find NumPy: the zip is for another system, or Krita has a Python other than 3.13. The message names the Python version Krita has.
  • Layer ... is a grouplayer and similar: select a paint layer in the Layers docker.
  • PARAMS: the message names the parameter and lists every value form allowed.
